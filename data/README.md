# Data policy

The repository contains only small, original demo fixtures generated by `Database.seed_demo_data`. Runtime databases and downloaded datasets are ignored by Git.

## Optional public dataset

The supported public adapter targets the [UCI AI4I 2020 Predictive Maintenance Dataset](https://archive.ics.uci.edu/dataset/601/ai4i):

- DOI: `10.24432/C5HS5C`
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Published purpose: synthetic data reflecting industrial predictive-maintenance observations
- Verified CSV SHA-256: `DC6630CD9B1F0F853922FAD78A1B6436570D3F1EC863F1DD5C4340AC56BC8A8E`

Download the dataset from UCI, place `ai4i2020.csv` under `data/raw`, and run:

```powershell
opsflow import-ai4i data/raw/ai4i2020.csv
```

The adapter groups rows by the dataset's `Type` field and creates a stable minute-by-minute demonstration timeline. This is an explicit transformation for workflow testing; it is not represented as original field telemetry.

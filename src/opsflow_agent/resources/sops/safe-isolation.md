# Safe Isolation Demo Procedure

This original procedure is a portfolio fixture. It must be replaced by an approved site-specific procedure before operational use.

## Preconditions

Only a qualified operator may isolate equipment. Identify the asset, notify affected personnel, review stored-energy hazards, and obtain the locally required work authorization before starting.

## Isolation

Stop the process through the normal control path when safe to do so. Isolate every approved energy source, apply the locally authorized lockout and tagout controls, and record the responsible operator and isolation time.

## Verification

Verify zero-energy state with an approved test method. A command to start must not energize the isolated asset. If the result is ambiguous, stop the workflow and escalate to a qualified reviewer.

## Return to service

Inspect safeguards, remove tools and temporary materials, account for personnel, and obtain independent approval before removing isolation controls. Resume in a monitored mode and record the first measurements.

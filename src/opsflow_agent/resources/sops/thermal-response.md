# Thermal Abnormality Demo Procedure

This original procedure provides generic workflow evidence and is not an equipment specification.

## Detection

Compare process temperature with the approved asset baseline, the concurrent air temperature, load, torque, and cooling status. A single measurement should not be treated as root-cause proof.

## Immediate response

For overheating with high load, machine-failure signals, smoke, odor, or damaged safeguards, place the asset in a safe state through the approved isolation procedure. Do not bypass alarms or increase limits to keep production running.

## Investigation

Inspect the cooling path, airflow restrictions, lubrication, load profile, sensor condition, and recent maintenance history. Preserve timestamps and measurements so another reviewer can reproduce the conclusion.

## Restart gate

Restart requires an identified and corrected cause, measurements inside approved limits, functional safeguards, and authorization from the responsible reviewer. Monitor temperature and load during the controlled restart.
